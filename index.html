SYSTEMS PROGRAMMING // C11

OS-FS: Custom Cross-Platform Virtual File System & File Manager

Low-level custom virtual filesystem and directory navigator with native POSIX and Win32 abstraction layers.

Source Code

Problem Solved

Modern high-level runtime environments abstract away operating system kernel storage primitives. Built entirely in pure C11 to master low-level directory traversal, file metadata inspection, memory-bounded string sanitization, and unified path operations across divergent Linux and Windows system calls.

Architecture & Implementation

Engineered a preprocessor platform-isolation layer mapping POSIX primitives (opendir, readdir, mkdir, chdir) and Win32 direct I/O. Features a command-line interface and an integrated Raylib GUI with bounded circular path buffers and defensive error handling via errno.

Technical Challenge

Preventing buffer overflows and path-traversal vulnerabilities during arbitrary input path navigation, alongside resolving incompatible directory separator formats between Unix (/) and Windows (\).

Solution & Engineering

Implemented deterministic string trimming routines (trim_newline, bounded fgets), normalized path delimiters, and built unified boundary checks that reject illegal parent escapes before issuing OS kernel requests.

Sub-millisecond path resolution overhead
Zero external runtime dependencies
Dual compilation target (GCC Linux / MinGW Windows)
C11 POSIX System Calls Win32 I/O GCC / Clang Raylib GUI Memory Bounds
FULL-STACK REALTIME // REACT • FIRESTORE

CampusBite: Real-Time Canteen Ordering & Kitchen Queue Engine

High-concurrency campus ordering portal with live bidirectional kitchen status synchronization and atomic inventory tracking.

Source Code

Problem Solved

Physical queues at college food courts create extreme bottlenecks during brief 15-minute intervals. Designed a digital ordering architecture allowing students to browse dynamically categorized menus, customize carts, and track live meal preparation tokens in real time.

Architecture & Implementation

Built with a modular React frontend connecting to Cloud Firestore via reactive snapshot listeners. Synchronizes student-facing order status tokens with a live kitchen management board across distinct state phases: Placed → Preparing → Ready for Pickup → Completed.

Technical Challenge

Handling concurrent order spikes at class break times where simultaneous checkouts for limited items caused race conditions and negative inventory counts.

Solution & Engineering

Employed Firestore atomic transactions (runTransaction) to ensure read-then-write consistency on inventory counts during checkout, coupled with optimistic client UI rendering for zero-latency user feedback.

Reduced order placement latency by ~60%
Sub-200ms real-time state synchronization across devices
Zero inventory race conditions under concurrent testing
React.js Firebase Firestore Firebase Authentication Atomic Transactions JavaScript ES6+ Responsive CSS3
ENTERPRISE WEB • RBAC // NODE.JS

EduTrack: Role-Based Academic & Attendance Management Platform

Multi-tenant institutional system featuring attendance tracking, grade recording, and secure parent portal visibility.

Source Code

Problem Solved

Replaces manual paper attendance registers and delayed monthly reports with an automated platform enabling instant student/teacher logging, automatic attendance shortage calculations, and verified parent portal access.

Architecture & Implementation

Architected with a 4-tier Role-Based Access Control (Admin, Faculty, Student, Parent) on Node.js and Firestore. Parents authenticate via unique Student Registration IDs to view individualized attendance graphs and evaluation metrics without accessing other students' records.

Technical Challenge

Preventing unauthorized cross-tenant data access while maintaining performant bulk operations when instructors record attendance for 60+ students simultaneously.

Solution & Engineering

Implemented Firestore batched writes to submit entire classroom rosters in single atomic operations, backed by server-validated security rules that isolate student documents to authorized auth claims.

Classroom attendance logging reduced from 10m to under 30s
Automated threshold alerts for attendance falling below 75%
100% role isolation verified with security rules unit tests
Node.js Express.js Cloud Firestore Firebase Auth RBAC Architecture Batched Operations

Terminal-Agent: Autonomous Multi-Provider Agent with Vector Retrieval

Zero-dependency terminal agent orchestrating shell command execution, structured JSON schema tool calling, and vector context indexing.

Source Code

Problem Solved

Command-line AI copilots are typically tied to proprietary single-vendor APIs with bulky dependency trees. Developed a clean, standard-library Python engine supporting multiple providers with tool calling and vector retrieval (supported by official MongoDB Academy AI Agents certification).

Architecture & Implementation

Structured around an autonomous tool execution loop: user brief → LLM function call request → schema-validated bash execution → vector database retrieval → synthesis. Natively interoperates with OpenAI, Anthropic, Gemini, Groq, and local Ollama instances.

Technical Challenge

Preventing destructive commands (e.g. unbounded recursive deletions or network leaks) during autonomous multi-step execution while maintaining conversational momentum.

Solution & Engineering

Constructed an interactive safety interceptor with explicit command confirmation flags, execution timeouts, non-zero exit code error analysis, and vector-backed documentation validation before execution.

Zero third-party pip dependencies (Python stdlib only)
